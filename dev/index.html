JTools.lsq — Method
x, P = lsq(r, x0)

Nonlinear Least Squares This function computes the parameters 'x' that minimize the weighted norm of a nonlinear multivariate function r(x) = [r₁(x); r₂(x); ...; rₙ(x)].

minₓ J = 1/2 rᵀ(x) W r(x)

Alternatively, the residuals function can be provided as a vector of functions, and the equivalent problem to be minimized becomes

minₓ J = 1/2 ∑ᵢ rᵢᵀ(x) Wᵢ rᵢ(x)

where each rᵢ can be a different multivariate function of x. Caution: rᵢ shall return a vector, so, if the output is a scalar, rᵢ shall return [rᵢ].

NB: usually in estimation problems r(x) = h(x) - y, where y are stacked noisy measurements and h(x) is the nonlinear measurement model.

Inputs: r Residuals function handle, r(x) = [r₁; r₂; ...], or r = (r₁(x), r₂(x), ...) x0 Initial guess for x

Outputs: x Solution to the least-squares problem P Covariance matrix of the solution (only meaningful when W is provided)

Author: F. Capolupo European Space Agency, 2020

JTools.montecarloConfidence — Method
L = montecarloConfidence(P, Nsim, Nfail)

Compute the confidence level L of the probability of success P given Nfail failed simulations over Nsim simulations.

Examples

julia> montecarloConfidence(0.997, 1000, 0)
0.950585606425314

References

[1] ECSS‐E‐ST‐60‐20C Rev. 1 page 77

JTools.montecarloNsim — Function
Nsim = montecarloNsim(P, L, Nfail)

Compute the minimum number of simulations Nsim needed to verify a probability of success P with confidence level L, knowing the number of failed simulations Nfail. If the number of simulations exceeds 100_000, the function returns -1.

Examples

julia> montecarloNsim(0.997, 0.95, 0)
997

References

[1] ECSS-E-ST-60-20C Rev.1, Section E-1
